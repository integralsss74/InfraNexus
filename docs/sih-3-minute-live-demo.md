# PAIMANA AI: 3-Minute Smart India Hackathon Live Demo Script

## Before the jury begins

Keep six browser tabs ready in this order: **Dashboard**, **Project Explorer**, **P-0732 project detail**, **What-if Simulator**, **AI Assistant**, and **Early Warnings**. Begin on the Dashboard. Keep the map at its default all-India view and ensure the demonstration dataset disclaimer is visible. One person should operate the product; one person should speak; a third member, if present, should only manage timing and handle questions.

> **Delivery rule:** Do not call the product a live government deployment. Say that it is a *synthetic technology demonstration designed for a governed authorised-data pilot*.

## The jury should see these four proofs

| Proof | What to point at | Why it matters |
|---|---|---|
| **Portfolio scale** | Dashboard KPIs and early-warning feed | Shows this is more than a single-project tracker. |
| **Functional spatial filter** | Maharashtra Leaflet map marker and the 105-project result | Demonstrates a real interactive feature, not a static map. |
| **Explainability** | P-0732 contributors, trajectory, and evidence | Shows that a risk score can be inspected and challenged by a human reviewer. |
| **Responsible action workflow** | Simulation labels, grounded AI response, alert export | Demonstrates governance, not uncontrolled automation. |

## Recovery lines for a live-demo issue

If the map tiles load slowly, say: “The product supports Leaflet-based spatial filtering; the paired state control applies the same verified filter.” Use the Maharashtra state selector immediately.

If the assistant response is delayed, say: “The controlled query layer only answers from structured portfolio evidence. We have prepared the relevant project drill-through to show the result.” Then open P-0732.

If time is running out, skip the simulator and say: “The same workflow also includes controlled what-if simulation; I will show it during questions.” Do not skip the map click, project explainability, or responsible-AI statement.

## Presentation discipline

Speak slowly and show only the screen area you are discussing. Do not read every KPI. Every click should answer a jury question: **Where is the risk? Why is it happening? What can the team review next?** Avoid claiming that the system makes official decisions, predicts the future with certainty, or uses live government data. The winning message is that PAIMANA AI creates an explainable, governed, and implementation-ready infrastructure review workflow.
